# English Prep

Интерактивный тренажёр для подготовки к контролю по английскому (L1 Économie / Gestion / CUPGE, семестр 1).
Interactive trainer for the English assessment.

## Разделы / Sections
- **Контроль / Exam** — протокол: письменный QCM + понимание текста (TD 8), устная презентация 5 минут (TD 9–10).
- **Грамматика / Grammar** — Grammar MCQ 1–7 с листочков + дополнительные Practice MCQ 8–11: 180 вопросов с объяснениями на RU/EN.
- **Тексты / Texts** — File 1 (UK riots), File 2 (The Conspirator) + дополнительные File 3–6 (Four-day week, Rosa Parks, Fast fashion, AI at work): аудио и текстовая версия, вопросы, пропуски, глоссарий, диктанты.
- **Лексика / Vocabulary** — 7 тем: список, карточки, тест, пары; поиск по словам.
- **Устный / Oral** — структура презентации, критерии B2, фразы, таймер на 5 минут.
- **Пробный тест / Mock** — случайные вопросы на время.

Сайт статический (HTML/CSS/JS), без сборки. Интерфейс RU/EN, светлая/тёмная тема, адаптирован под телефон.
Прогресс хранится в `localStorage` браузера.

Запуск локально: открыть `index.html` или `python -m http.server`.
